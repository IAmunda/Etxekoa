# Etxekoa - Proyecto HTML Optimizado

## Descripción

Este repositorio contiene proyectos HTML educativos que han sido completamente optimizados y modernizados siguiendo las mejores prácticas actuales de desarrollo web.

## Cambios Realizados

### ✅ Optimizaciones Generales

1. **Estructura HTML mejorada**
   - Añadido `lang="es"` para especificar el idioma
   - Añadidas meta tags de viewport para diseño responsive
   - Corregidas etiquetas HTML mal anidadas o sin cerrar
   - Añadidas meta descriptions para SEO

2. **Accesibilidad mejorada**
   - Añadidos atributos `alt` descriptivos en todas las imágenes
   - Implementados roles ARIA apropiados
   - Añadida navegación por teclado
   - Links de "Saltar al contenido" para lectores de pantalla

3. **CSS optimizado**
   - Separación de estilos inline a archivos CSS externos
   - Eliminación de código CSS duplicado
   - Implementación de diseño responsive
   - Mejores prácticas en nomenclatura de clases

4. **Semántica mejorada**
   - Uso de etiquetas semánticas (`header`, `main`, `nav`, `section`)
   - Estructura lógica de encabezados (h1, h2, h3)
   - Mejor organización del contenido
